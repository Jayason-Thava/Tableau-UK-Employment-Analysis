# 💼 UK Employment Data Visualization (Tableau Project)

## 📌 Project Overview
This project is a Tableau practice exercise using a dataset focused on **UK employment statistics**.  
The goal was to explore employment patterns across cities and industries using a variety of visualization techniques.  
Key skills practiced include geographic mapping, bar charts, heat maps, bubble maps, and applying filters and titles for clarity.

🔗 [View the Dashboard on Tableau Public](https://public.tableau.com/app/profile/jayason.thavathevathasan/viz/Employementdataset/UKEmployementData)

---

## 🎯 Objectives
- Visualize employment data using multiple chart types.
- Use filters to allow users to interact with the dashboard.
- Add descriptive titles and labels to improve readability.
- Practice dashboard layout and design in Tableau.

---

## 📊 Visualizations Included

### 1. Geographic Map – Average Employment % by City
- **Purpose:** Show average employment percentage across UK cities.
- **Features:**  
  - Geographic plotting  
  - City-level granularity  
  - Title: *"Average Employment % by City"*

### 2. Bar Chart – Employment Change per Industry
- **Purpose:** Compare employment changes across industries.
- **Features:**  
  - Industry filter  
  - Axis labels and sorting  
  - Title: *"Employment Change by Industry"*

### 3. Heat Map – Top 10 Industries by Employment
- **Purpose:** Highlight the top 10 industries based on employment figures.
- **Features:**  
  - Color-coded intensity  
  - Industry ranking  
  - Title: *"Top 10 Industries by Employment"*

### 4. Bubble Map – Employment by City
- **Purpose:** Visualize employment volume across cities using bubble size.
- **Features:**  
  - Bubble size represents employment count  
  - Interactive tooltips  
  - Title: *"Employment Distribution by City"*

---

## 📈 Dashboard Features
All visualizations were combined into a single dashboard titled **"UK Employment Insights"**.

- **Filters included:**
  - Industry
  - City
  - Year
- **Design elements:**
  - Clear titles for each chart
  - Interactive filters for user exploration
  - Consistent layout and color scheme
